# pkg-rpm-audioreach-graphmgr

RPM packaging for
[audioreach-graphmgr](https://github.com/AudioReach/audioreach-graphmgr) on
CentOS Stream 10 (aarch64).

audioreach-graphmgr provides the AudioReach Audio Graph Manager (AGM) for
Qualcomm platforms. AGM manages audio sessions, devices, and metadata for
the AudioReach framework. It provides the AGM service library, sound card
parser, and tinyalsa PCM/mixer plugins.
